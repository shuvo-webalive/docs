---
title: "Installation"
description: "Clone the SDK for your language and point your project at it."
---

The SDKs are not published to a package registry. Each one lives in its own Bitbucket repository,
and you install it by cloning that repository and pointing your project at the clone.

<Note>
  You need read access to the SDK repositories on Bitbucket. Clone the `development` branch: it is
  the main branch, and the repository's default branch does not carry the SDK.
</Note>

Keep the clone next to your project, because the paths below are relative:

```text
projects/
├── webcommander-sdk-<language>/   the clone
└── my-app/                        your project
```

## Install the SDK

<Tabs>
  <Tab title="Python">
    Requires [uv](https://docs.astral.sh/uv/getting-started/installation/) 0.8.4 or newer and `git`.
    uv provides Python 3.10 to 3.13 itself.

    <Steps>
      <Step title="Clone and sync">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-python.git
        cd webcommander-sdk-python
        uv sync
        ```
      </Step>
      <Step title="Add it to your project">
        In `my-app/pyproject.toml`:

        ```toml
        [project]
        name = "my-app"
        version = "0.1.0"
        requires-python = ">=3.10"
        dependencies = ["webcommander-sdk"]

        [tool.uv.sources]
        webcommander-sdk = { path = "../webcommander-sdk-python", editable = true }
        ```

        Then run `uv sync` in `my-app`. Not using uv? Run `pip install -e ../webcommander-sdk-python`
        instead.
      </Step>
      <Step title="Import it">
        ```python
        from webcommander import build_client
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="JavaScript">
    Requires Node.js 18 or newer.

    <Steps>
      <Step title="Clone and install">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-js.git
        cd webcommander-sdk-js
        npm install
        ```
      </Step>
      <Step title="Add it to your project">
        In `my-app/package.json`:

        ```json
        {
          "name": "my-app",
          "type": "module",
          "dependencies": {
            "webcommander-sdk": "file:../webcommander-sdk-js"
          }
        }
        ```

        Then run `npm install` in `my-app`.
      </Step>
      <Step title="Import it">
        ```js
        import {WebCommanderClient} from 'webcommander-sdk';
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="PHP">
    Requires PHP 8.2 or newer with the `ctype`, `curl`, `filter`, `json` and `mbstring` extensions,
    and Composer 2.

    <Steps>
      <Step title="Clone and install">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-php.git
        cd webcommander-sdk-php
        composer install
        ```
      </Step>
      <Step title="Add it to your project">
        From inside `my-app` (run `composer init` first if it has no `composer.json`):

        ```bash
        composer config repositories.wcsdk path ../webcommander-sdk-php
        composer require webcommander/sdk:@dev
        ```
      </Step>
      <Step title="Import it">
        ```php
        use WebCommander\Sdk\Client\WebCommanderClient;
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Java">
    Requires JDK 17 or newer and Maven 3.9 or newer.

    <Steps>
      <Step title="Clone and install">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-java.git
        cd webcommander-sdk-java
        mvn install -DskipTests
        ```

        This puts the jar in your local Maven repository, so your project needs no path to it.
      </Step>
      <Step title="Add it to your project">
        In `my-app/pom.xml`:

        ```xml
        <dependency>
            <groupId>com.webcommander</groupId>
            <artifactId>webcommander-sdk</artifactId>
            <version>3.5.0</version>
        </dependency>
        ```

        The SDK logs through SLF4J. Add a binding such as `slf4j-simple` or `logback-classic` to see
        its logs.
      </Step>
    </Steps>
  </Tab>
  <Tab title=".NET">
    Requires the .NET SDK 8.0.100 or newer.

    <Steps>
      <Step title="Clone and pack">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-dotnet.git
        cd webcommander-sdk-dotnet
        dotnet pack src/WebCommander.Sdk -c Release -o ./artifacts
        ```
      </Step>
      <Step title="Add it to your project">
        From inside `my-app`:

        ```bash
        dotnet nuget add source ../webcommander-sdk-dotnet/artifacts --name webcommander-local
        dotnet add package WebCommander.Sdk
        ```
      </Step>
      <Step title="Import it">
        ```csharp
        using WebCommander.Sdk.Client;
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Dart">
    Requires Dart 3.5 or newer. The Flutter SDK includes Dart.

    <Steps>
      <Step title="Clone and get packages">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-dart.git
        cd webcommander-sdk-dart
        dart pub get
        ```
      </Step>
      <Step title="Add it to your project">
        In `my-app/pubspec.yaml`:

        ```yaml
        name: my_app

        environment:
          sdk: ^3.5.0

        dependencies:
          webcommander_sdk:
            path: ../webcommander-sdk-dart
        ```

        Then run `dart pub get` in `my-app`.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Go">
    Requires Go 1.24 or newer. The SDK uses only the standard library.

    <Steps>
      <Step title="Clone and build">
        ```bash
        git clone --branch development git@bitbucket.org:webalive/webcommander-sdk-go.git
        cd webcommander-sdk-go
        go build ./...
        ```
      </Step>
      <Step title="Add it to your project">
        In `my-app/go.mod`:

        ```text
        module example.com/my-app

        go 1.24

        require bitbucket.org/webalive/webcommander-sdk-go/v3 v0.0.0

        replace bitbucket.org/webalive/webcommander-sdk-go/v3 => ../webcommander-sdk-go
        ```

        `v0.0.0` is a placeholder that the `replace` line overrides.
      </Step>
      <Step title="Import it">
        ```go
        import wc "bitbucket.org/webalive/webcommander-sdk-go/v3"
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Updating

Run `git pull` in the clone. Python, JavaScript, PHP, Dart and Go read the clone directly, so the
change is live in your project at once. Java and .NET use a built copy, so rebuild after pulling:

- **Java:** run `mvn install -DskipTests` in the clone again.
- **.NET:** run `dotnet pack` in the clone again. NuGet caches a package by its version number, so
  if the version did not change, clear the cache with `dotnet nuget locals global-packages --clear`
  before you restore `my-app`.
