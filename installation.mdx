---
title: "Installation"
description: "Install the SDK for your language from its package registry or from GitHub."
---

Each SDK is published to its language's package registry, and its source code is public on GitHub.
Install it either way: from the package registry, which is the usual choice, or straight from the
GitHub repository.

| Language | Package | GitHub repository |
| --- | --- | --- |
| Python | [`webcommander`](https://pypi.org/project/webcommander/) on PyPI | [WebCommanderCMS/webcommander-sdk-python](https://github.com/WebCommanderCMS/webcommander-sdk-python) |
| JavaScript | [`webcommander`](https://www.npmjs.com/package/webcommander) on npm | [WebCommanderCMS/webcommander-sdk-js](https://github.com/WebCommanderCMS/webcommander-sdk-js) |
| PHP | [`webcommander/webcommander`](https://packagist.org/packages/webcommander/webcommander) on Packagist | [WebCommanderCMS/webcommander-sdk-php](https://github.com/WebCommanderCMS/webcommander-sdk-php) |
| Java | [`com.webcommander:webcommander`](https://central.sonatype.com/artifact/com.webcommander/webcommander) on Maven Central | [WebCommanderCMS/webcommander-sdk-java](https://github.com/WebCommanderCMS/webcommander-sdk-java) |
| .NET | [`WebCommander`](https://www.nuget.org/packages/WebCommander) on NuGet | [WebCommanderCMS/webcommander-sdk-dotnet](https://github.com/WebCommanderCMS/webcommander-sdk-dotnet) |
| Dart | [`webcommander`](https://pub.dev/packages/webcommander) on pub.dev | [WebCommanderCMS/webcommander-sdk-dart](https://github.com/WebCommanderCMS/webcommander-sdk-dart) |
| Go | [`github.com/WebCommanderCMS/webcommander-sdk-go/v4`](https://pkg.go.dev/github.com/WebCommanderCMS/webcommander-sdk-go/v4) | [WebCommanderCMS/webcommander-sdk-go](https://github.com/WebCommanderCMS/webcommander-sdk-go) |

## Requirements

| Language | Requires |
| --- | --- |
| Python | Python 3.10 or newer |
| JavaScript | Node.js 20.19 or newer |
| PHP | PHP 8.2 or newer with the `ctype`, `curl`, `filter`, `json` and `mbstring` extensions, and Composer 2 |
| Java | JDK 17 or newer and Maven 3.9 or newer |
| .NET | .NET SDK 8.0.100 or newer |
| Dart | Dart 3.5 or newer. The Flutter SDK includes Dart |
| Go | Go 1.24 or newer. The SDK uses only the standard library |

## Option 1: install from the package registry

<Tabs>
  <Tab title="Python">
    ```bash
    pip install webcommander
    ```

    With uv, run `uv add webcommander` instead.
  </Tab>
  <Tab title="JavaScript">
    ```bash
    npm install webcommander
    ```
  </Tab>
  <Tab title="PHP">
    ```bash
    composer require webcommander/webcommander
    ```
  </Tab>
  <Tab title="Java">
    In `pom.xml`, using the latest version shown on
    [Maven Central](https://central.sonatype.com/artifact/com.webcommander/webcommander):

    ```xml
    <dependency>
        <groupId>com.webcommander</groupId>
        <artifactId>webcommander</artifactId>
        <version>VERSION</version>
    </dependency>
    ```

    The SDK logs through SLF4J. Add a binding such as `slf4j-simple` or `logback-classic` to see its
    logs.
  </Tab>
  <Tab title=".NET">
    ```bash
    dotnet add package WebCommander
    ```
  </Tab>
  <Tab title="Dart">
    ```bash
    dart pub add webcommander
    ```

    In a Flutter app, run `flutter pub add webcommander` instead.
  </Tab>
  <Tab title="Go">
    From inside your module:

    ```bash
    go get github.com/WebCommanderCMS/webcommander-sdk-go/v4
    ```
  </Tab>
</Tabs>

## Option 2: install from GitHub

<Tabs>
  <Tab title="Python">
    ```bash
    pip install git+https://github.com/WebCommanderCMS/webcommander-sdk-python.git
    ```

    With uv, run `uv add git+https://github.com/WebCommanderCMS/webcommander-sdk-python.git` instead.
  </Tab>
  <Tab title="JavaScript">
    ```bash
    npm install github:WebCommanderCMS/webcommander-sdk-js
    ```
  </Tab>
  <Tab title="PHP">
    From inside your project:

    ```bash
    composer config repositories.webcommander vcs https://github.com/WebCommanderCMS/webcommander-sdk-php
    composer require webcommander/webcommander:dev-main
    ```
  </Tab>
  <Tab title="Java">
    <Steps>
      <Step title="Clone and install">
        ```bash
        git clone https://github.com/WebCommanderCMS/webcommander-sdk-java.git
        cd webcommander-sdk-java
        mvn install -DskipTests
        ```

        This puts the SDK in your local Maven repository.
      </Step>
      <Step title="Add the dependency">
        In `pom.xml`, using the version in the repository's own `pom.xml`:

        ```xml
        <dependency>
            <groupId>com.webcommander</groupId>
            <artifactId>webcommander</artifactId>
            <version>VERSION</version>
        </dependency>
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title=".NET">
    <Steps>
      <Step title="Clone and pack">
        ```bash
        git clone https://github.com/WebCommanderCMS/webcommander-sdk-dotnet.git
        cd webcommander-sdk-dotnet
        dotnet pack src/WebCommander.Sdk -c Release -o ./artifacts
        ```
      </Step>
      <Step title="Add it to your project">
        From inside your project, with the clone next to it:

        ```bash
        dotnet nuget add source ../webcommander-sdk-dotnet/artifacts --name webcommander-local
        dotnet add package WebCommander
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Dart">
    ```bash
    dart pub add webcommander --git-url=https://github.com/WebCommanderCMS/webcommander-sdk-dart.git
    ```

    This adds a `git` dependency to `pubspec.yaml`.
  </Tab>
  <Tab title="Go">
    Go always installs from the GitHub repository, so this is the same command as option 1. To use a
    specific commit or branch, add it after `@`:

    ```bash
    go get github.com/WebCommanderCMS/webcommander-sdk-go/v4@main
    ```
  </Tab>
</Tabs>

## Updating

| Language | From the package registry | From GitHub |
| --- | --- | --- |
| Python | `pip install --upgrade webcommander` | Run the same `pip install git+...` command with `--upgrade` |
| JavaScript | `npm install webcommander@latest` | Run the same `npm install github:...` command again |
| PHP | `composer update webcommander/webcommander` | `composer update webcommander/webcommander` |
| Java | Change `<version>` in `pom.xml` | `git pull` in the clone, then `mvn install -DskipTests` again |
| .NET | `dotnet add package WebCommander` | `git pull` in the clone, then `dotnet pack` again |
| Dart | `dart pub upgrade webcommander` | `dart pub upgrade webcommander` |
| Go | `go get github.com/WebCommanderCMS/webcommander-sdk-go/v4@latest` | Same as the package registry |

Each repository's `CHANGELOG.md` lists what changed in every release.
