---
title: "Retrieve a redirect"
description: "Returns the redirect whose `id` you pass as `redirect_id`."
openapi: "GET /admin/settings/seo_configuration/redirects/{redirect_id}"
---

Returns one redirect under the `redirect` key, with the same three fields a listing row has: `id`, `source_url` and `destination_url`. If no redirect has that `redirect_id`, including one you deleted, the call returns `404 not_found`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
