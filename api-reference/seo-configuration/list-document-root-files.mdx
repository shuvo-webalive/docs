---
title: "List document root files"
description: "Returns up to 100 document root files per call, with paging details."
openapi: "GET /admin/settings/seo_configuration/document_root"
---

Returns the files the site serves from fixed paths, such as a site verification file or `ads.txt`. The files are under `items`, with a `pagination` block. Each row gives the file's `config_key`, which [Delete a document root file](/api-reference/seo-configuration/delete-a-document-root-file) takes as `config_key`, and its `file_name` and `file_path`. Send `limit` and `offset` to page through the files.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
