---
title: "Update a payment gateway"
description: "Changes only the fields you send on a payment gateway and returns the whole gateway."
openapi: "PATCH /admin/payment_gateways/{payment_gateway_id}"
---

Send only the fields you want to change, at the top level of the body, not wrapped in `payment_gateway`. Fields you leave out keep their values, and `allowed_for` merges key by key, so `{"allowed_for": {"store_pickup": false}}` leaves `shipping` and `delivery` as they were. `information: null` clears the text, and `zone` takes a zone's `id` or `{"id": ...}`. [Update a payment gateway with PUT](/api-reference/payment-gateways/update-a-payment-gateway-with-put) behaves the same way.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
