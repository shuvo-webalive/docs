---
title: "Delete the custom loader"
description: "Removes your uploaded loader image and returns `204` with no body."
openapi: "DELETE /admin/settings/animation_effects/custom_loader"
---

Removes the uploaded loader image and returns `204` with no body. It also returns `204` when no loader was uploaded. Afterwards `preloader_design.custom_loader` reads `enabled: false`, with `null` for `file_name` and `file_url`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
