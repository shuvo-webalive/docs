---
title: "Get a settings section"
description: "Returns one settings section under its own key, such as `widget_transition`."
openapi: "GET /admin/settings/animation_effects/{section}"
---

Returns one section, wrapped in the section's own name rather than in `animation_effects`, and without `group_meta`. Its values are the same as that section's in [Get animation effects settings](/api-reference/animation-effects/get-animation-effects-settings). Add `field_metadata=true` to also get the rules for each of the section's fields except `custom_loader`, keyed by field name. An unknown section returns `404 not_found`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
