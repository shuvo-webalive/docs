---
title: "List country taxes"
description: "Returns a page of up to 100 country taxes under `country_taxes`, newest first, and how many exist in `pagination.total`."
openapi: "GET /admin/tax/country-taxes"
---

Returns your store's country taxes under `country_taxes`, newest first, up to `limit` per call with a maximum of `100`. You also get a `pagination` object with the total and this page's `offset`, and `group_meta`, which describes `country_tax` and `state_rules` with a `kind`, a `writable` flag and an `href` each. Each country tax has twelve fields, including `state_rules_count`, the number of its state rules; [Retrieve a country tax](/api-reference/country-taxes/retrieve-a-country-tax) returns the rules themselves. To read every country tax, add `pagination.count` to `offset` after each page until `offset` reaches `pagination.total`. Send `sort=name` to sort by name. `q`, `search`, `country_code`, `is_rest_of_world` and `field_metadata` are accepted and ignored. The response has no `ETag`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
