---
title: "Create a country tax"
description: "Creates a country tax and returns it with its `id`, which other calls take as `country_tax_id`."
openapi: "POST /admin/tax/country-taxes"
---

Creates a country tax and returns it with the `id` the store assigned, which the other calls take as `country_tax_id`. Wrap the record in `country_tax` and include `country_code`, in any letter case. The store fills `country` from it, and sets `tax_code` to the country's code unless you send `tax_code`. No response includes `country_code`, and `country_id` is not read. `tax_method` takes `fixed_rate`, `api` or `no_tax` in any letter case and reads back in lower case. `name` is optional and reads `null` when you leave it out. Fields the store does not know are dropped, and you can create a second country tax for a country that already has one. To file the country tax under a transaction number, send an `X-Transaction-No` header, or `transaction_no` at the top level of the body beside `country_tax`. A `transaction_no` inside `country_tax` files nothing. The response has the twelve fields of a listing row, no `state_rules`, and no `ETag` or `Location` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
