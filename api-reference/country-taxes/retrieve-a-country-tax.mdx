---
title: "Retrieve a country tax"
description: "Returns the country tax whose `id` you pass as `country_tax_id`, with its state rules and an `ETag`."
openapi: "GET /admin/tax/country-taxes/{country_tax_id}"
---

Returns one country tax under the `country_tax` key. It has the twelve fields of a listing row plus `state_rules`, the list of the country tax's state rules. A country tax with no state rules has an empty `state_rules` list. The response has an `ETag` header, which you can send as `If-Match` on an update. Sending it back in `If-None-Match` still returns `200` and the full body.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
