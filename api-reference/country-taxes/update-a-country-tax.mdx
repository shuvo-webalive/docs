---
title: "Update a country tax"
description: "Changes only the fields you send and returns the updated country tax with its state rules and an `ETag`."
openapi: "PUT /admin/tax/country-taxes/{country_tax_id}"
---

Changes the fields you send inside `country_tax` and returns the updated country tax. Fields you leave out keep their values, so you do not send `country_code` again. A new `country_code` moves the country tax to that country, and `"tax_method": "no_tax"` sets `tax_rate` to `0`. Send an `If-Match` header with the `ETag` from your last read if you want the update rejected with `409` when the country tax changed since then. A `transaction_no` at the top level of the body, or in an `X-Transaction-No` header, files the country tax under that number, and its old number then returns `404`. The response has the twelve fields of a listing row plus `state_rules`, and an `ETag` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
