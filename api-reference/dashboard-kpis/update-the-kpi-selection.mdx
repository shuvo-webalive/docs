---
title: "Update the KPI selection"
description: "Sets the 2 to 5 KPI tiles the dashboard shows, for every admin, and returns them."
openapi: "PUT /admin/dashboard/kpi_selection"
---

Send `metrics`, the full list of 2 to 5 distinct metric keys in tile order. The list replaces the tiles of the store's default layout, so every admin sees the change at once. Read the current `selected` keys from [List KPI options](/api-reference/dashboard-kpis/list-kpi-options) first so you can send them back. `duration`, or `start_date` with `end_date`, sets the period of the figures in the response. Fields other than `metrics` are ignored.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
