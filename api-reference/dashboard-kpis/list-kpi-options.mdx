---
title: "List KPI options"
description: "Returns every metric a KPI tile can show, by group, and the keys now selected."
openapi: "GET /admin/dashboard/kpi_options"
---

Returns the 27 metrics in five `groups`, each metric with its `key`, `code`, `label`, `format` (`money`, `count` or `percent`) and `in_use`. `selected` lists the keys of the tiles the default layout shows now, `min` and `max` give the number of tiles allowed, and `dashboard` names the layout. Read this before [Update the KPI selection](/api-reference/dashboard-kpis/update-the-kpi-selection) to see the keys you can send.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
