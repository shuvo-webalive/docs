---
title: "Export customers"
description: "Every customer as an XLSX spreadsheet."
openapi: "GET /admin/customers/export"
---

Returns a spreadsheet of every customer. Filters are not applied: `status=active` does not narrow the export. Each of the 18 column parameters keeps its column when omitted or sent as `1`, `true`, `on` or `yes`, and removes it for any other value.

<Note>Every SDK sample assumes a client set up once, as shown on the [Customers overview](./overview).</Note>
