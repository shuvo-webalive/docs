---
title: "Check an email address"
description: "Checks whether an email address already belongs to a customer, and returns that customer's ids."
openapi: "GET /admin/customers/check-email"
---

Returns `exists`: `true` if a customer already has this email address, `false` if not. When the address is taken, the response also includes that customer's `customer_id` and `internal_id`. When it is free, `exists` is the only field, so read `exists` before you look for an id. Use the `customer_id` with the other customer endpoints. Deleted customers still count: a deleted customer's address returns `exists: true`, and creating a new customer with that address is rejected with `409`.
