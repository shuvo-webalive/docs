---
title: "Import customers"
description: "Creates or updates customers from an uploaded CSV, XLS or XLSX file."
openapi: "POST /admin/customers/import"
---

Upload the file in a multipart field named `file` (lowercase), with a filename ending in `.csv`, `.xls` or `.xlsx`, because the extension decides how the file is read. A filename without one of these extensions is rejected with `400 unsupported_file_type`. A row with a `customer_id` updates that customer and a row without one creates a customer; the `City/Suburb` and `State/Province` columns are not saved. Do not import an unedited file from [Export customers](/api-reference/customers/export-customers): the export contains every customer, so importing it updates every customer in the store.
