---
title: "Retrieve a customer"
description: "Returns one customer, with its addresses and custom properties, by `customer_id`."
openapi: "GET /admin/customers/{customer_id}"
---

Returns the customer in `customer`, including its `addresses` and `custom_properties`. Send the `customer_id` you got from List customers, Check an email address or Create a customer, not the `internal_id`. If you send an `internal_id`, you get `404`, or `200` with a different customer when that number is also another customer's `customer_id`. Check that the `customer_id` in the response matches the one you sent. Deleted customers stay in the trash: this call still returns them, with `is_in_trash` set to `true`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
