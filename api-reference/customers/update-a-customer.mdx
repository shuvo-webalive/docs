---
title: "Update a customer"
description: "Change only the fields you send; the rest stay as they are."
openapi: "PUT /admin/customers/{customer_id}"
---

Send only the fields that change; the rest are left alone. Sending `custom_properties` replaces the whole list rather than adding to it.

<Note>The SDK samples assume a client set up once, as shown in [Authentication](/authentication#set-up-a-client).</Note>
