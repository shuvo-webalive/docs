---
title: "Bulk reset passwords"
description: "Email a password reset to several customers."
openapi: "POST /admin/customers/bulk-reset-password"
---

Queues a password reset email for each id. Ids that match no customer are returned in `skipped` with a reason rather than failing the call. An empty list, or ids that are not integers, is refused with `400`.

<Note>The SDK samples assume a client set up once, as shown in [Authentication](/authentication#set-up-a-client).</Note>
