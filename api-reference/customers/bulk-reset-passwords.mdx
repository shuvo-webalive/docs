---
title: "Bulk reset passwords"
description: "Queues a password reset email for each customer id you send in `customer_ids`."
openapi: "POST /admin/customers/bulk-reset-password"
---

Queues a password reset email for each customer in `customer_ids`. Send `customer_id` values, not `internal_id`. The call is asynchronous: a `202` means the emails are queued, not that they have been sent. An id that matches no customer does not fail the call. It is returned in `skipped` as `{"customer_id": …, "reason": "not_found"}`. A call that queues nothing still returns `202`, so compare `queued` and `skipped` with the ids you sent. An empty `customer_ids` list, or an id that is not an integer, is rejected with `400 validation_failed`.

<Note>Each SDK sample is a complete program: it reads your credentials from the `WC_` environment variables listed in [Authentication](/authentication#set-up-a-client), sets up a client and makes the call. To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
