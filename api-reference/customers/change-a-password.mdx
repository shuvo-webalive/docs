---
title: "Change a password"
description: "Change a password by giving the old one."
openapi: "POST /admin/customers/{customer_id}/change-password"
---

Changes the password when `old_password` matches. A wrong old password is answered `401`, and so is a customer who is still `awaiting_verification`, even straight after a reset. The SDKs return that `401` as it is and do not retry it.

<Note>Every SDK sample assumes a client set up once, as shown on the [Customers overview](./overview).</Note>
