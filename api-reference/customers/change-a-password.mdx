---
title: "Change a password"
description: "Changes a customer's password after checking their current password."
openapi: "POST /admin/customers/{customer_id}/change-password"
---

Checks the customer's current password and, if it matches, replaces it with a new one. Inside `customer`, send the customer's `email`, their current password as `old_password` and the new password as `password`. A successful change returns `200`. A wrong `old_password` returns `401`. You also get `401` for any customer whose `status` is `awaiting_verification`, even straight after a [password reset](/api-reference/customers/reset-a-password), because that status has no usable login. To create a customer who can sign in, send `status: "active"` with a `password` to [Create a customer](/api-reference/customers/create-a-customer).
