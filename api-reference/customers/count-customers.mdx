---
title: "Count customers"
description: "The number of customers, optionally filtered."
openapi: "GET /admin/customers/count"
---

Returns the total as one key. `email`, `search`, `status`, `companyName`, `phone`, `city`, `state` and `customerGroup` narrow the total. `country`, the paging parameters, `sort` and the date ranges are accepted and ignored, so they return the unfiltered total.

<Note>The SDK samples assume a client set up once, as shown in [Authentication](/authentication#set-up-a-client).</Note>
