---
title: "Count customers"
description: "Returns the number of customers, or the number that match the filters you send."
openapi: "GET /admin/customers/count"
---

Returns one field, `total`: the number of customers that match the filters you send, or all customers when you send none. These parameters narrow the count: `search` (also `searchText`), `email`, `status`, `companyName`, `phone`, `city`, `state` and `customerGroup`. These are accepted but ignored, so they do not change the count: `country`, `limit`, `offset`, `page`, `sort`, `createdFrom`, `createdTo`, `updatedFrom` and `updatedTo`. An unknown parameter name, such as `max`, is rejected with `400 unknown_parameter`.
