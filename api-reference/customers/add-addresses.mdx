---
title: "Add addresses"
description: "Adds primary, shipping or billing addresses to a customer and returns the updated customer."
openapi: "POST /admin/customers/{customer_id}/addresses"
---

Adds one or more addresses to a customer. Send them as a list in `customer.addresses`, and give each one a `type` of `primary`, `shipping` or `billing`. [Create a customer](/api-reference/customers/create-a-customer) discards any address fields you send it, so use this call to add addresses. Any other `type` is rejected with `400 invalid_enum`. A `state` that is not in the address's `country` is rejected with `400 state_country_mismatch`, and the error names the field `addresses[0].state_id`, not `state`. On success you get `201` and the customer, including its updated `addresses` list.

<Note>Each SDK sample is a complete program: it reads your credentials from the `WC_` environment variables listed in [Authentication](/authentication#set-up-a-client), sets up a client and makes the call. To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
