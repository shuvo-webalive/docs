---
title: "Add addresses"
description: "Add shipping, billing or primary addresses to a customer."
openapi: "POST /admin/customers/{customer_id}/addresses"
---

Adds one or more addresses. `type` is `primary`, `shipping` or `billing`; any other value is refused with `400 invalid_enum`. A `state` that is not in the `country` is refused with `400 state_country_mismatch`.

<Note>The SDK samples assume a client set up once, as shown in [Authentication](/authentication#set-up-a-client).</Note>
