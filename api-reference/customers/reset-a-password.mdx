---
title: "Reset a password"
description: "Sets a new password for a customer without needing their current one."
openapi: "POST /admin/customers/{customer_id}/reset-password"
---

Sets a new password for a customer. You do not need their current password. Send the new password in `customer.password`. A successful reset returns `201`. A reset does not give a login to a customer whose `status` is `awaiting_verification`, because that status has no usable login. [Change a password](/api-reference/customers/change-a-password) still returns `401` for them straight after the reset. To create a customer who can sign in, send `status: "active"` with a `password` to [Create a customer](/api-reference/customers/create-a-customer).
