---
title: "List store credit adjustments"
description: "Returns a customer's store credit adjustments, newest first, up to 20 at a time."
openapi: "GET /admin/customers/{customer_id}/store-credit/adjustments"
---

To get the next page, send the response's `pagination.next_page` as `page`; it is `null` when there are no more pages. Only `limit`, `offset` and `page` change the result: `sort`, an `action` filter and unknown parameters are ignored, not rejected. Entries do not include `balance_before` or `balance_after`, so save them from the [Adjust store credit](/api-reference/customers/adjust-store-credit) response each time you make an adjustment. You cannot rebuild a customer's balance from this list, because setting `store_credit` with [Update a customer](/api-reference/customers/update-a-customer) changes the balance without adding an entry.
