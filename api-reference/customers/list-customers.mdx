---
title: "List customers"
description: "Returns up to 20 customers per call, with the total count and the next page's URL."
openapi: "GET /admin/customers"
---

Returns up to 20 customers per call in `customers`. `pagination` gives you `total`, the number of customers across all pages; `has_next`, which is `true` when there is another page; and `next_page`, the URL of that page. Parameter names are case-sensitive. An unknown or wrongly cased name, such as `firstName`, `max` or `postcode`, is rejected with `400 unknown_parameter`, and `errors[0]` in the response names the parameter. `createdFrom`, `createdTo`, `updatedFrom` and `updatedTo` are accepted but ignored: they do not narrow the results. Listed customers do not include `custom_properties`; to get them, use [Retrieve a customer](/api-reference/customers/retrieve-a-customer).

<Note>Each SDK sample is a complete program: it reads your credentials from the `WC_` environment variables listed in [Authentication](/authentication#set-up-a-client), sets up a client and makes the call. To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
