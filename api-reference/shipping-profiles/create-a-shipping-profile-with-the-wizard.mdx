---
title: "Create a shipping profile with the wizard"
description: "Creates a shipping profile with its rules, rates and zones in one call."
openapi: "POST /admin/shipping_profiles/wizard"
---

Send the profile inside `shipping_profile`, with `shipping_rules` as a list of rules to create. Each rule needs a `name`, and takes a `description`, a `shipping_class` `id`, `zones` and a `shipping_rate` that has a `name`, a `method` and the cost fields described in [Create a shipping rate](/api-reference/shipping-rates/create-a-shipping-rate). A zone is `{"id": 5}` for an existing zone, or `{"name": "Inner West"}`, which creates a new zone with that name. A new profile `name` returns `201` with a `Location` header. A `name` that a profile already has adds the new rules to that profile, keeps its `id` and returns `200`. If any value is bad, nothing is saved. A body with only `{"shipping_profile": {"name": "..."}}` creates a profile with no rules. The response does not list the zones the call created: read them from the `zones` of each rule, with [Retrieve a shipping rule](/api-reference/shipping-rules/retrieve-a-shipping-rule).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
