---
title: "Create a shipping profile"
description: "Creates a shipping profile and returns it with its `id`, which other calls take as `shipping_profile_id`."
openapi: "POST /admin/shipping_profiles"
---

Send the fields inside `shipping_profile`; only `name` is required. `rule_preference` defaults to `product_assigned_rule`, and `shipping_rules` lists the `id` of each rule to put on the profile. The response is the new profile, with a `Location` header that holds its URL. Send `default` as `true` to make it the store default. Send `suggest_name` as `true` to get the next free name, such as `Metro profile(1)`, when another profile has the `name`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
