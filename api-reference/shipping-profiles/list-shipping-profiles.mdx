---
title: "List shipping profiles"
description: "Returns up to 20 shipping profiles per call, newest first, with paging details."
openapi: "GET /admin/shipping_profiles"
---

Returns the shipping profiles in `shipping_profiles`, 20 per call unless you send `limit`, and a `pagination` block. The newest profile comes first unless you send `sort` and `order`. Filter with `search` and `default`. A query parameter the listing does not know is ignored. When several parameters are invalid, the `400` response lists each one in `details`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
