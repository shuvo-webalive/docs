---
title: "Get search settings"
description: "Returns all three search settings sections and a `group_meta` block describing each one."
openapi: "GET /admin/settings/search_settings"
---

Returns every search setting under `search_settings`, with all three sections in full: `searchable_content`, `search_fields` and `synonyms`. Beside it, `group_meta` gives each section's `kind`, whether it is `writable`, and the `href` of its own path. Add `field_metadata=true` to also get a description of every field, keyed by section. The response has no `ETag` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
