---
title: "Get a search settings section"
description: "Returns one search settings section under its own key, such as `search_fields`."
openapi: "GET /admin/settings/search_settings/{section}"
---

Returns one section, wrapped in the section's own name rather than in `search_settings`, and without `group_meta`. The section is the same as the one [Get search settings](/api-reference/search-settings/get-search-settings) returns for it. Add `field_metadata=true` to also get a description of each of the section's fields, keyed by field name. An unknown section returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
