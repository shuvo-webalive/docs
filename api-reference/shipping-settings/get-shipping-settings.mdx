---
title: "Get shipping settings"
description: "Returns all seven shipping settings, and `group_meta` saying whether you can write them."
openapi: "GET /admin/settings/shipping_settings"
---

Returns the seven shipping settings under `shipping_settings`, with `group_meta` beside them. The three profile fields each hold the profile's `{id, name}` record or `null`, and the other four are `true` or `false`. Send `field_metadata=true` to also get a description of each field, keyed by field name. The response has no `ETag` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
