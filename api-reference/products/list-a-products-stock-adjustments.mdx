---
title: "List a product's stock adjustments"
description: "Returns the product's stock changes, newest first, with paging details."
openapi: "GET /admin/products/{product_id}/stock/adjustments"
---

Returns the product's stock adjustments under `adjustments`, newest first, with a `pagination` block. Page with `limit`, which defaults to `20`, and `offset`. Each row has the change as `delta` (the new figure minus the old one), its `note`, who made it and when. Every row returns `transaction_no` as `null`, also for a change you sent with a `transaction_no`. `HEAD` on this path returns `404`.

To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
