---
title: "Upload images to a product"
description: "Stores one or more base64-encoded images on the product and returns the images it stored."
openapi: "POST /admin/products/{product_id}/image"
---

Send JSON: wrap the files in `product.image_and_video.images`, each with a `filename` and the file's bytes as base64 text in `base64`. You can send several files in one call. A multipart body is rejected with `415`. The store keeps each file under your `filename` with a UUID and `_` in front. To add one image at a chosen `position`, use [Add an image to a product's media](/api-reference/products/add-an-image-to-a-products-media).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
