---
title: "Add an image to a product's media"
description: "Stores one base64-encoded image on the product and returns the stored image as one row."
openapi: "POST /admin/products/{product_id}/media"
---

Send JSON at the top level of the body, with no wrapper: `type` set to `images`, a `filename`, and `content`, which is the file's bytes as base64 text or a `data:image/png;base64,...` address. `position` is optional. Only images are accepted. A multipart body is rejected with `415`. The store keeps the file under your `filename` with a UUID and `_` in front. To store several files in one call, use [Upload images to a product](/api-reference/products/upload-images-to-a-product).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
