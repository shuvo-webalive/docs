---
title: "Patch a product"
description: "Changes the product fields you send, keeps every other field, and returns the product, the same way `PUT` does."
openapi: "PATCH /admin/products/{product_id}"
---

Send the fields to change at the top level of the body, not inside `product`. This call takes the same body as [Update a product](/api-reference/products/update-a-product) and merges it the same way: a field you leave out keeps its value, inside nested blocks too. A body that changes nothing, `{}` included, returns `200` with the product unchanged. The flat names such as `base_price` and `is_featured` are still accepted; the response shows the changed values in `pricing.base_price` and `advanced.product_flags.featured.enabled`. A product in the trash is rejected with `409`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
