---
title: "List a product's reviews"
description: "Returns the product's reviews, 20 per call by default, with paging details."
openapi: "GET /admin/products/{product_id}/reviews"
---

Returns the reviews of the product whose `id` you pass as `product_id`, under `reviews`, with a `pagination` block. Page with `limit` (`1` to `100`, default `20`) and `offset`. `status` and `page` are ignored: a request sent with `status=pending` still returns approved reviews. Each review is the same record [Import a product's reviews](/api-reference/products/import-a-products-reviews) returns. `HEAD` on this path returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
