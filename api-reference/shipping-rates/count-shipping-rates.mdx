---
title: "Count shipping rates"
description: "Returns the number of shipping rates that match the listing's filters, as `total`."
openapi: "GET /admin/shipping_rates/count"
---

Returns the number of shipping rates as `total`, at the top level of the body. The `search`, `method` and `handling_cost` filters of [List shipping rates](/api-reference/shipping-rates/list-shipping-rates) narrow the count the same way.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
