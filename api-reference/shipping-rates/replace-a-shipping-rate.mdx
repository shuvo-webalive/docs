---
title: "Replace a shipping rate"
description: "Replaces a shipping rate with the fields you send in `shipping_rate`, and returns it."
openapi: "PUT /admin/shipping_rates/{shipping_rate_id}"
---

Send the whole rate inside `shipping_rate`. `name`, `method`, `calculate_for_entire_order` and `price_entered_with_tax` are required, with the costs the `method` uses, `handling_cost` and `additional_rule`; `handling_cost` and `additional_rule` take `null`. Each required field you leave out is named in the `400` response with the reason `required` and the message `PUT replaces the whole rate; send every field or use PATCH`. To change only some fields, use [Update a shipping rate](/api-reference/shipping-rates/update-a-shipping-rate).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
