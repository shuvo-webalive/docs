---
title: "Check a shipping rate"
description: "Returns `200` and headers only when the shipping rate exists, and `404` when it does not."
openapi: "HEAD /admin/shipping_rates/{shipping_rate_id}"
---

Returns `200` with headers only and no body when a shipping rate has the `shipping_rate_id` you pass, and `404` when none does. To read the rate, use [Retrieve a shipping rate](/api-reference/shipping-rates/retrieve-a-shipping-rate).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
