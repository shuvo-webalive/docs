---
title: "List shipping rates"
description: "Returns up to 20 shipping rates per call, newest first, with paging details."
openapi: "GET /admin/shipping_rates"
---

Returns the shipping rates in `shipping_rates`, 20 per call unless you send `limit`, and a `pagination` block. The newest rate comes first unless you send `sort` and `order`. Filter with `search`, `method` and `handling_cost`. A query parameter the listing does not know is ignored. When several parameters are invalid, the `400` response lists each one in `details`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
