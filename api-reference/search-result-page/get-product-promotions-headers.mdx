---
title: "Get product promotions headers"
description: "Returns the headers for the product promotions listing, with no body."
openapi: "HEAD /admin/settings/page_settings/search_result_page/product_promotion"
---

Returns `200` with headers only and no body. The response has no `ETag` header. Use it to check that the promotions are reachable without downloading them.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
