---
title: "Start an order preview"
description: "Prices the products you send and returns a preview session, without placing an order."
openapi: "POST /admin/orders/preview"
---

Send the fields at the top level of the body, not wrapped in `order`; only `products` is required. The store prices the products, taxes, shipping and handling, and returns them with a `session` that holds the `session_id` every other call takes as `preview_session_id`. No order is created, and the preview expires 30 minutes after it starts. Send `customer_id` to use the customer's saved addresses, or send `billing_address`, and `shipping_address` for a product that ships.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
