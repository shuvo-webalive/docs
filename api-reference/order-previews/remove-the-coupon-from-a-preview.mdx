---
title: "Remove the coupon from a preview"
description: "Removes the applied coupon, so the totals return to what they were before it."
openapi: "DELETE /admin/orders/preview/{preview_session_id}/coupon"
---

Removes the coupon and returns `204` with no body. [Retrieve an order preview](/api-reference/order-previews/retrieve-an-order-preview) then shows the totals the preview had before you applied the coupon. This call moves `session.expires_at` to 30 minutes after the call.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
