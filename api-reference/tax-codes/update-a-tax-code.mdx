---
title: "Update a tax code"
description: "Changes a tax code and returns it. Send `priority` and `resolver_type` every time."
openapi: "PUT /admin/tax_codes/{tax_code_id}"
---

Changes the fields you send and returns the tax code. Wrap the fields in `tax_code`; you can leave out `name`. `name`, `label`, `description` and `rate` keep their stored values when you leave them out, but `priority` is set to `0` and `resolver_type` to `flat`, so send both in every update. A `default: true` in the body is stored as `false`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
