---
title: "List customer groups"
description: "Returns customer groups, 20 per call or the `limit` you send, sorted by `name` by default."
openapi: "GET /admin/customer_groups"
---

Returns the customer groups under `customer_groups`, sorted by `name` unless you send `sort`, with a `pagination` block. Send `search_text` to keep only groups whose `name` contains that text, and `status` to keep only active or inactive groups. Query parameters this call does not list, such as `q`, are ignored. The response has no `ETag` or `Last-Modified` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
