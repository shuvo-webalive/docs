---
title: "Update a checkout"
description: "Sets the delivery type and the billing and shipping addresses and returns the priced checkout."
openapi: "PATCH /admin/orders/checkout/{session_id}"
---

Send `delivery_type`, `billing_address` and `shipping_address` at the top level of the body; no other field is taken. Each address you send replaces the whole address, and a field you leave out reads `""`. Shipping and handling follow the shipping address, so send it with `delivery_type`. A `store_pickup` has no shipping cost. A `shipping` or `delivery` checkout needs the store to have a default shipping profile; see [Update shipping settings](/api-reference/shipping-settings/update-shipping-settings).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
