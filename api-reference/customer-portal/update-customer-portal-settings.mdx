---
title: "Update customer portal settings"
description: "Changes the fields you send in one or more writable sections and returns all settings."
openapi: "PATCH /admin/settings/customer_portal"
---

Send the fields to change inside `customer_portal`, grouped by section name: `portal`, `registration`, `login` or `sso`. One body can change several sections. Only the fields you send change; other fields in the same block, and sections you leave out, keep their stored values. Returns all the settings after the change, with `group_meta`, as [Get customer portal settings](/api-reference/customer-portal/get-customer-portal-settings) does.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
