---
title: "Check the sales report"
description: "Returns `200` and the headers of the sales report, with no body."
openapi: "HEAD /admin/dashboard/reports/sales"
---

Returns `200` with headers only and no body, after checking the same query as [Get the sales report](/api-reference/dashboard-reports/get-the-sales-report). A bad value in the query is rejected with `400`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
