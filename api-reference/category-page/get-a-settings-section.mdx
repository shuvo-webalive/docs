---
title: "Get a settings section"
description: "Returns one settings section under its own key, such as `category_information`."
openapi: "GET /admin/settings/page_settings/category_page/{section}"
---

Returns one section, wrapped in the section's own name rather than in `category_page`, and without `group_meta`. Add `field_metadata=true` to also get a description of each of the section's fields, keyed by field name. An unknown section returns `404 not_found`.

## SDK method

| SDK | Call |
| --- | --- |
| Python | `client.category_page.get_category_page_section()` |
| JavaScript | `client.categoryPage.getCategoryPageSection()` |
| PHP | `CategoryPage::getCategoryPageSection()` |
| Java | `client.categoryPage().getCategoryPageSection()` |
| .NET | `client.CategoryPage.GetCategoryPageSectionAsync()` |
| Dart | `client.categoryPage.getCategoryPageSection()` |
| Go | `client.CategoryPageSettings().GetCategoryPageSection()` |

<Note>Each call above gives you the response body documented on this page. The SDK samples use a client you set up once, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
