---
title: "Get category page settings headers"
description: "Returns the headers for the category page settings, with no body."
openapi: "HEAD /admin/settings/page_settings/category_page"
---

Returns `200` with headers only and no body. The headers include `Content-Length: 0` and an `ETag`. Use it to check that the settings are reachable without downloading them.

## SDK method

| SDK | Call |
| --- | --- |
| Python | `client.category_page.head_category_page()` |
| JavaScript | `client.categoryPage.headCategoryPage()` |
| PHP | `CategoryPage::headCategoryPage()` |
| Java | `client.categoryPage().headCategoryPage()` |
| .NET | `client.CategoryPage.HeadCategoryPageAsync()` |
| Dart | `client.categoryPage.headCategoryPage()` |
| Go | `client.CategoryPageSettings().HeadCategoryPage()` |

<Note>Each call above gives you the response body documented on this page. The SDK samples use a client you set up once, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
