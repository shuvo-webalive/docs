---
title: "List dashboard layouts"
description: "Returns every dashboard layout with its `id`, `name` and whether it is the default."
openapi: "GET /admin/dashboards"
---

Returns all the store's dashboard layouts under `dashboards`, in one call with no paging. Each row has `id`, `name`, `default`, `created_at` and `updated_at`, and exactly one row has `default` `true`. The rows do not include sections or KPI tiles: pass a row's `id` as `dashboard_id` to [Retrieve a dashboard layout](/api-reference/dashboards/retrieve-a-dashboard-layout) to read them. Query parameters you add are ignored.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
