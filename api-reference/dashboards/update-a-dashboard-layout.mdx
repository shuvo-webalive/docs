---
title: "Update a dashboard layout"
description: "Changes only the fields you send and returns the whole layout."
openapi: "PATCH /admin/dashboards/{dashboard_id}"
---

Send only what changes. Sections are matched by `key`, so `standard_sections` with `{"key": "announcement", "visible": false}` hides that section and leaves every other section as it is. A `position` on a customisable section or on a tab reorders the others to fit. `kpis` replaces the layout's KPI tiles. `default` `true` makes this layout the default for every admin. Sending `default` `false` for a layout that is not the default returns `200` and changes nothing.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
