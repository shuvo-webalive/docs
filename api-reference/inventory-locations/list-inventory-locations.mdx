---
title: "List inventory locations"
description: "Returns up to 20 inventory locations per call, or the `limit` you send, default location first, with paging details."
openapi: "GET /admin/inventory_locations"
---

Returns the inventory locations, 20 per call unless you send `limit`, with a `pagination` block. The default location comes first, then the rest, newest `created_at` first. Send `q` to keep only locations whose `name` contains that text. Only `q`, `limit` and `offset` are accepted; any other query parameter, such as `page` or `field_metadata`, is rejected with `400`. After a `400`, the next one or two requests on the same connection can return that rejection's body instead of their own.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
