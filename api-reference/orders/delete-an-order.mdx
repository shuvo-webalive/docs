---
title: "Delete an order"
description: "Deletes an order permanently. An unknown `order_id` also returns `200`, with `status` `not_found`."
openapi: "DELETE /admin/orders/{order_id}"
---

Deletes the order permanently and returns `"status": "deleted"` with the order's `order_id` and `internal_id`. Retrieving the order afterwards returns `404`, and [Count orders](/api-reference/orders/count-orders) goes down by one. When no order has that `order_id`, for example because you already deleted it, the call still returns `200`, with `"status": "not_found"`, so read `status` rather than the HTTP status. Stock the order already took, at the point set by the store's `update_stock` setting, is not given back.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
