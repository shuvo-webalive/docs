---
title: "Create an order with a payment"
description: "Creates an order and records one payment on it, returning the order with `paid` and `due`."
openapi: "POST /admin/orders/with-payment"
---

Send the same fields as [Create an order](/api-reference/orders/create-an-order) plus a `payment` record, which is required; `customer` and `customer_id` both name the customer. The store files the payment under gateway `API` with `payment_method` `API`, whatever you send: it keeps `amount` and `track_info`, stores `payer_info` and `transaction_reference` as `""`, and sets `transaction_date` to the time of the call. The order's own `transaction_no` and `external_reference_order_id` are accepted and not stored, and an `X-Transaction-No` header does not file the order under a transaction number either. **A new store ships nothing until it has a default shipping profile.** Without one, every order with `delivery_type` `shipping` or `delivery` is refused with `400` and the message `We do not ship to your location. Please choose a different shipping address.` Create a profile with [Create a shipping profile with the wizard](/api-reference/shipping-profiles/create-a-shipping-profile-with-the-wizard), then set it as `default_shipping_profile` with [Update shipping settings](/api-reference/shipping-settings/update-shipping-settings): creating the profile alone is not enough. `store_pickup` and `others_shipping` orders need no profile. See [Prepare a new store](/prepare-a-new-store).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
