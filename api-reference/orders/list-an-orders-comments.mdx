---
title: "List an order's comments"
description: "Returns all of an order's comments, oldest first, in one list."
openapi: "GET /admin/orders/{order_id}/comments"
---

Returns every comment on the order under `comments`, oldest first, without paging. An order with no comments returns `"comments": []`. Each comment matches the response to [Add a comment to an order](/api-reference/orders/add-a-comment-to-an-order), and `limit` is ignored.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
