---
title: "Send an order's invoice"
description: "Emails the invoice of the order whose `internal_id` you pass to its billing email address."
openapi: "POST /admin/orders/{order_internal_id}/send-invoice"
---

Pass the order's `internal_id`, not its `order_id`: this path finds the order by `internal_id`, so an `order_id` returns `404` or emails the invoice of the order whose `internal_id` has that number. The call needs no body. The response names the address in `sent_to`, the time in `sent_at`, and `template` as `send-invoice`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
