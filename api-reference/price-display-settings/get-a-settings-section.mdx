---
title: "Get a settings section"
description: "Returns one settings section under its own key, such as `order_item`."
openapi: "GET /admin/settings/price_display_settings/{section}"
---

Returns one section, wrapped in the section's own name rather than in `price_display_settings`, and without `group_meta`. Its values are the same as that section's part of [Get price display settings](/api-reference/price-display-settings/get-price-display-settings). Add `field_metadata=true` to also get a description of the section's fields, under the section's own name. An unknown section returns `404 not_found`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
