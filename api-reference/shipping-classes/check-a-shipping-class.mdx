---
title: "Check a shipping class"
description: "Returns `200` and headers only, even when no class has the `shipping_class_id` you pass."
openapi: "HEAD /admin/shipping_classes/{shipping_class_id}"
---

Returns `200` with headers only: no body and no `ETag`. It returns `200` even when no shipping class has the `shipping_class_id` you pass, so it does not tell you whether the class exists. To check that, use [Retrieve a shipping class](/api-reference/shipping-classes/retrieve-a-shipping-class), which returns `404` when no class has that `shipping_class_id`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
