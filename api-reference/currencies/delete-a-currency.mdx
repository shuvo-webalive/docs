---
title: "Delete a currency"
description: "Deletes a currency permanently. You cannot delete the base currency."
openapi: "DELETE /admin/currencies/{currency_id}"
---

Deletes the currency permanently and returns `204` with no body. The currency leaves the listing, the count goes down by one, and retrieving or deleting it again returns `404`. You cannot delete the base currency: make another currency the base first with [Set the base currency](/api-reference/currencies/set-the-base-currency).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
