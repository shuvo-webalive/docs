---
title: "Retrieve a currency"
description: "Returns the currency whose `id` you pass as `currency_id`, with an `ETag` header."
openapi: "GET /admin/currencies/{currency_id}"
---

Returns one currency under the `currency` key, with the same eleven fields a listing entry has. The response has an `ETag` header, which changes when the currency changes. Send `field_metadata=true` to add a description of each field beside `currency`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
