---
title: "Check a currency"
description: "Returns headers only for the currency you pass as `currency_id`, including its `ETag`."
openapi: "HEAD /admin/currencies/{currency_id}"
---

Returns `200` with headers only and no body when a currency has that `currency_id`, and `404` when none does. The `ETag` header is the same one [Retrieve a currency](/api-reference/currencies/retrieve-a-currency) returns, so you can check whether the currency changed without reading it.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
