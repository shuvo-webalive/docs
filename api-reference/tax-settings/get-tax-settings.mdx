---
title: "Get tax settings"
description: "Returns all nine tax settings in one `tax_settings` object."
openapi: "GET /admin/tax/settings"
---

Returns the store's tax settings as nine fields in one flat `tax_settings` object, with no sections. Query parameters have no effect: `field_metadata=true` returns the same body and no field descriptions. The response has no `ETag` or `Last-Modified` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
