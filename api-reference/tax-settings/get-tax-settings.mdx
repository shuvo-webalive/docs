---
title: "Get tax settings"
description: "Returns the nine tax settings in one `tax_settings` object, and `group_meta`."
openapi: "GET /admin/settings/tax"
---

Returns the store's tax settings as nine fields in one flat `tax_settings` object, with no sections. `group_meta` names the settings, the tax profiles and the tax rules. Send `field_metadata=true` to also get `field_metadata`, a description of each field.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
