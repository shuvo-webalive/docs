---
title: "Update tax settings"
description: "Changes the tax settings you send inside `tax_settings` and returns all nine."
openapi: "PUT /admin/settings/tax"
---

Send the fields to change inside a `tax_settings` object. Only those fields change; the others keep their stored values. Returns all nine settings under `tax_settings`, in the same shape as [Get tax settings](/api-reference/tax-settings/get-tax-settings). A body wrapped in `settings`, or with no wrapper, is rejected with `400`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
