---
title: "Check a country"
description: "Returns the headers of one country, including its `ETag`, with no body."
openapi: "HEAD /admin/countries/{country_id}"
---

Returns `200` with headers only and no body. The `ETag` is the same one [Retrieve a country](/api-reference/countries/retrieve-a-country) returns for that country, whichever form of `country_id` you send.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
