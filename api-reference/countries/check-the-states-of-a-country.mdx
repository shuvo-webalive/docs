---
title: "Check the states of a country"
description: "Returns the headers of a country's state list, including its `ETag`, with no body."
openapi: "HEAD /admin/countries/{country_id}/states"
---

Returns `200` with headers only and no body. The `ETag` is the same one [List the states of a country](/api-reference/countries/list-the-states-of-a-country) returns for that country when you send no query parameters.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
