---
title: "Delete a variation type"
description: "Deletes a variation type permanently. Send `cascade=true` to delete its options with it."
openapi: "DELETE /admin/variations/{variation_id}"
---

Deletes the type permanently and returns `204` with no body. The type leaves the listing, and retrieving or deleting it again returns `404`. A type that has options is deleted only with `cascade=true`, which deletes its options too. A type that a product's variants use cannot be deleted, even with `cascade=true` and even after that product is moved to the trash.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
