---
title: "Delete all of a product's variants"
description: "Deletes every variant of the product whose `id` you pass as `product_id`."
openapi: "DELETE /admin/products/{product_id}/variations"
---

Deletes every variant of the product and returns `204` with no body. It also returns `204` when the product has no variants. [List a product's variants](/api-reference/variations/list-a-products-variants) then returns `{"variations": []}`. To delete one variant, use [Delete a product's variant](/api-reference/variations/delete-a-products-variant).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
