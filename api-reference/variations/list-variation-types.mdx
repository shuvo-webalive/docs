---
title: "List variation types"
description: "Returns variation types with their options, by ascending `id`, 20 per call unless you send `limit`."
openapi: "GET /admin/variations"
---

Returns the variation types in ascending order of each type's `id`, 20 per call unless you send `limit`. Each type comes with every one of its options. `pagination` gives the number of matching types in `total`, and `has_next` is `true` while another page follows. Send `search` to keep only types whose `name` contains that text, and `standard` to keep only one kind of type. Any query parameter not listed here is rejected with `400`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
