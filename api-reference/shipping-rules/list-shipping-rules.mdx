---
title: "List shipping rules"
description: "Returns up to 20 shipping rules per call, newest first, with paging details."
openapi: "GET /admin/shipping_rules"
---

Returns the shipping rules in `shipping_rules`, 20 per call unless you send `limit`, and a `pagination` block. The newest rule comes first unless you send `sort` and `order`. Filter with `search`, `shipping_class_id`, `zone_id`, `method` and `handling_cost`; a rule is listed once even when it matches several zones. A query parameter the listing does not know is ignored. When several parameters are invalid, the `400` response lists each one in `details`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token (New)](/api-reference/authentication/get-an-access-token-new), or from [Get an access token (Legacy)](/api-reference/authentication/get-an-access-token) if your store signs in with a redirect URI and an auth string.</Note>
