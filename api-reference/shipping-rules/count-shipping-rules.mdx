---
title: "Count shipping rules"
description: "Returns the number of shipping rules that match the listing's filters, as `total`."
openapi: "GET /admin/shipping_rules/count"
---

Returns the number of shipping rules as `total`, at the top level of the body. The filters of [List shipping rules](/api-reference/shipping-rules/list-shipping-rules) narrow the count the same way.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
