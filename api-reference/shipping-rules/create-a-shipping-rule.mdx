---
title: "Create a shipping rule"
description: "Creates a shipping rule and returns it with its `id`, which other calls take as `shipping_rule_id`."
openapi: "POST /admin/shipping_rules"
---

Send the fields inside `shipping_rule`; only `name` is required. The response is the new rule, with a `Location` header that holds its URL. Send `profile_id` to put the new rule on a shipping profile. Send `suggest_name` as `true` to get the next free name, such as `Metro(1)`, when another rule has the `name`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
