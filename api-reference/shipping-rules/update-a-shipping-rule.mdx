---
title: "Update a shipping rule"
description: "Changes only the fields you send inside `shipping_rule` and returns the rule."
openapi: "PATCH /admin/shipping_rules/{shipping_rule_id}"
---

Send only the fields to change, inside `shipping_rule`; every field you leave out keeps its value. `zones` is the full new list of zones, not an addition. A `shipping_rate` or `shipping_class` of `null` takes it off the rule, and the rate or class stays in the store. An `id` in the body is rejected with `400`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
