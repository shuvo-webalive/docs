---
title: "Count blog posts"
description: "Returns the number of blog posts, narrowed by `ids`, `category` or `visibility` if you send them."
openapi: "GET /admin/blogs/count"
---

Returns the number of blog posts as `count`, inside a `blogs` object. `ids`, `category` and `visibility` narrow the number as they narrow [List blog posts](/api-reference/blogs/list-blog-posts), so it matches that listing's `pagination.total` for the same filters. The listing's other parameters are accepted and change nothing, and any other parameter is rejected with `400`. Posts in the trash are not counted.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
