---
title: "Retrieve a comment"
description: "Returns the comment whose `id` you pass as `blog_comment_id`."
openapi: "GET /admin/blogs/{blog_id}/comments/{blog_comment_id}"
---

Returns the comment under `comment`, with the same twelve fields as its entry in the comment listing. The top-level `id` is the blog post's `id`, not the comment's. It also returns a comment on a blog post in the trash.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
