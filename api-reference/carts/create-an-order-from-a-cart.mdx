---
title: "Create an order from a cart"
description: "Turns the cart into an order, empties the cart and returns the new order."
openapi: "POST /admin/orders/carts/{session_id}"
---

Creates an order from the cart's items, empties the cart, and returns the order under `order` with `status` set to `success`. Send the customer's `customer_id`; it is the only required field, and `payment_gateway` defaults to `PIS`. The new order has `order_status` `in_progress`, `payment_status` `unpaid`, and one `order_line_details` entry per cart item. It gets the customer's saved addresses unless you sent addresses to [Update a cart item](/api-reference/carts/update-a-cart-item) with the same `JSESSIONID` cookie as this call. To file the order under a transaction number, send the `X-Transaction-No` header or `transaction_no` in the body; when the two differ, the header wins. **A new store ships nothing until it has a default shipping profile.** Without one, every order with `delivery_type` `shipping` or `delivery` is refused with `400` and the message `We do not ship to your location. Please choose a different shipping address.` Create a profile with [Create a shipping profile with the wizard](/api-reference/shipping-profiles/create-a-shipping-profile-with-the-wizard), then set it as `default_shipping_profile` with [Update shipping settings](/api-reference/shipping-settings/update-shipping-settings): creating the profile alone is not enough. `store_pickup` and `others_shipping` orders need no profile. See [Prepare a new store](/prepare-a-new-store).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
