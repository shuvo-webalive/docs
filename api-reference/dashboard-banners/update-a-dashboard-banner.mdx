---
title: "Update a dashboard banner"
description: "Changes only the fields you send and returns the banner."
openapi: "PATCH /admin/dashboard/banners/{banner_key}"
---

Send only what changes. The change shows on the dashboard of every admin. `learn_more` and `try_it` are replaced whole, and `"try_it": null` removes the second button. `position` moves the banner and renumbers the others. `active` `false` hides the banner from [Get the dashboard feed](/api-reference/dashboard-banners/get-the-dashboard-feed) and keeps it in the list. `key` cannot be sent.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
