---
title: "List dashboard banners"
description: "Returns every dashboard banner in `position` order, active and hidden ones."
openapi: "GET /admin/dashboard/banners"
---

Returns all the store's dashboard banners under `banners`, in one call with no paging. Each banner has its `key`, `position`, `active`, `icon`, `title`, `description`, `tags`, `learn_more` and `try_it`. To read only the banners the dashboard shows, use [Get the dashboard feed](/api-reference/dashboard-banners/get-the-dashboard-feed). Query parameters you add are ignored.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
