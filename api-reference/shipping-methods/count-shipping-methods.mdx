---
title: "Count shipping methods"
description: "Returns the number of shipping methods in the store."
openapi: "GET /admin/shipping_methods/count"
---

Returns the number of shipping methods as `count`, inside a `shipping_methods` object. The number matches `pagination.total` from the listing. Query parameters are accepted and ignored, so nothing narrows the count.

## SDK method

| SDK | Call |
| --- | --- |
| Python | `client.shipping_methods.count_shipping_methods()` |
| JavaScript | `shippingMethods.countShippingMethods()` |
| PHP | `ShippingMethods::countShippingMethods()` |
| Java | `client.shippingMethods().countShippingMethods()` |
| .NET | `client.ShippingMethods.CountShippingMethodsAsync()` |
| Dart | `client.shippingMethods.countShippingMethods()` |
| Go | `client.ShippingMethods().CountShippingMethods()` |

<Note>Each call above gives you the response body documented on this page. The SDK samples use a client you set up once, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
