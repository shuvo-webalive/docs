---
title: "Check the shipping methods list"
description: "Checks that the shipping methods list is reachable. Returns headers only, with no body."
openapi: "HEAD /admin/shipping_methods"
---

Returns `200` with headers only and no body. Neither this response nor the listing has an `ETag` header.

## SDK method

| SDK | Call |
| --- | --- |
| Python | `client.shipping_methods.head_shipping_methods()` |
| JavaScript | `shippingMethods.headShippingMethods()` |
| PHP | `ShippingMethods::headShippingMethods()` |
| Java | `client.shippingMethods().headShippingMethods()` |
| .NET | `client.ShippingMethods.HeadShippingMethodsAsync()` |
| Dart | `client.shippingMethods.headShippingMethods()` |
| Go | `client.ShippingMethods().HeadShippingMethods()` |

<Note>Each call above gives you the response body documented on this page. The SDK samples use a client you set up once, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
