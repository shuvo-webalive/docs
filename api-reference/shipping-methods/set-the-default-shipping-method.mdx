---
title: "Set the default shipping method"
description: "Makes a shipping method the default and removes the flag from the previous one."
openapi: "PUT /admin/shipping_methods/{shipping_method_id}/default"
---

Makes this method the default and returns it with `is_default` set to `true`. The method that was the default loses the flag. The call reads no body, so anything you send is ignored. No call clears the flag without giving it to another method.

## SDK method

| SDK | Call |
| --- | --- |
| Python | `client.shipping_methods.set_shipping_method_default()` |
| JavaScript | `shippingMethods.setShippingMethodDefault()` |
| PHP | `ShippingMethods::setShippingMethodDefault()` |
| Java | `client.shippingMethods().setShippingMethodDefault()` |
| .NET | `client.ShippingMethods.SetShippingMethodDefaultAsync()` |
| Dart | `client.shippingMethods.setShippingMethodDefault()` |
| Go | `client.ShippingMethods().SetShippingMethodDefault()` |

<Note>Each call above gives you the response body documented on this page. The SDK samples use a client you set up once, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
