---
title: "Get checkout page settings"
description: "Returns all six checkout page settings sections, and a `group_meta` block describing each one."
openapi: "GET /admin/settings/page_settings/checkout_page"
---

Returns all six sections under `checkout_page`. The two address sections list only their active field keys, in `active_fields`; [Get a settings section](/api-reference/checkout-page/get-a-settings-section) returns their full field list. Beside the settings, `group_meta` gives each section's `kind`, whether it is `writable`, and the `href` of its own path. Add `field_metadata=true` to also get a description of each section's fields, keyed by section.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
