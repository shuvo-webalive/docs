---
title: "Create a custom tax profile"
description: "Creates a custom tax profile and returns it; other calls take its `id` as `custom_profile_id`."
openapi: "POST /admin/tax/custom-profiles"
---

Creates a custom tax profile and returns it with the profile's `id`, which the other calls take as `custom_profile_id`. Wrap the record in `custom_profile`; `name` is required, and `description` and `tax_code` are optional. Any `code` you send is discarded, and fields the store does not know are dropped. To file the profile under a transaction number, send an `X-Transaction-No` header, or `transaction_no` at the top level of the body beside `custom_profile`. A `transaction_no` inside `custom_profile` files nothing. The response has the eight fields of a listing row and no `ETag`. A new profile holds no rules, so its `rules_count` is `0`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
