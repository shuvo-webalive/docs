---
title: "List custom tax profiles"
description: "Returns a page of up to 100 custom tax profiles under `custom_profiles`, newest first, and how many exist in `pagination.total`."
openapi: "GET /admin/tax/custom-profiles"
---

Returns your custom tax profiles under `custom_profiles`, newest first, up to `limit` per call with a maximum of `100`. You also get a `pagination` object with the `total` number of profiles and `has_next`, which says whether more profiles follow, and `group_meta`, which describes `custom_profile` and `rules` with a `kind`, a `writable` flag and an `href` each. Each profile gives its number of rules in `rules_count`; to get the rules themselves, use [Retrieve a custom tax profile](/api-reference/custom-tax-profiles/retrieve-a-custom-tax-profile). Send `sort=name` to sort by name. `q`, `search` and `field_metadata` are accepted and ignored. The response has no `ETag`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
