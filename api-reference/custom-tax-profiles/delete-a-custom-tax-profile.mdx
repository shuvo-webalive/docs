---
title: "Delete a custom tax profile"
description: "Deletes a custom tax profile permanently. Returns `204` with no body."
openapi: "DELETE /admin/tax/custom-profiles/{custom_profile_id}"
---

Deletes the profile whose `id` you pass as `custom_profile_id` and returns `204` with no body. Retrieving it afterwards returns `404`. Deleting it again returns `400`, not `404`, with the code `invalid_request` and the message `Profile not found`. If the request just before this one on the same client was rejected with `404`, the store returns that `404` for the delete and deletes nothing. Retrieve the profile afterwards to confirm it is gone.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
