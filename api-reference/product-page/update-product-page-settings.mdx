---
title: "Update product page settings"
description: "Changes the fields you send in one or more sections and returns all the settings."
openapi: "PATCH /admin/settings/page_settings/product_page"
---

Send the fields to change, grouped by section name, inside `product_page` or with no wrapper at all. Only the fields you send change: other fields in the same block, and every section you leave out, keep their stored values. One body can change several sections at once. Returns all the settings after the change, with `group_meta`, as [Get product page settings](/api-reference/product-page/get-product-page-settings) does.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string. To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
