---
title: "List trash types"
description: "Returns every type the trash holds, in alphabetical order, such as `Category` and `Customer`."
openapi: "GET /admin/trash/types"
---

Returns the types in `types`, each as an object with a `type` field, in alphabetical order. Each value is a PascalCase name, such as `BlogPost`, that you can send as `trash_type` in a path, as `type` in a bulk item and as `type` on [List items in the trash](/api-reference/trash/list-items-in-the-trash). The call takes no query parameters: any one you send is rejected with `400`. The response has no `ETag` header.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
