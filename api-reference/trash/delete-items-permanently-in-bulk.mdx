---
title: "Delete items permanently in bulk"
description: "Deletes up to 100 trashed items permanently and returns the deleted items and the items that failed."
openapi: "POST /admin/trash/bulk-delete"
---

Send the same body as [Restore items in bulk](/api-reference/trash/restore-items-in-bulk): `items`, a list of 1 to 100 objects, each with the item's `type` and `id`. You get `200` when every item is deleted, and `207` with the same body when any item fails, even if none is deleted, so check `failed` in every response. `deleted` lists each deleted item with its `type`, `id` and `name`, and `failed` lists each failed item with its `type`, `id`, `code` and `message`. The `code` is `not_in_trash` for an item that is not in the trash and `not_found` for an id the type does not have. An item listed twice is deleted once and reported once.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
