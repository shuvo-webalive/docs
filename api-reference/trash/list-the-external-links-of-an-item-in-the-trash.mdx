---
title: "List the external links of an item in the trash"
description: "Returns the links outside the store that deleting the trashed item permanently would break."
openapi: "GET /admin/trash/{trash_type}/{trash_item_id}/external_links"
---

Returns the item's `type` and `id`, and `links`, the links outside the store that a permanent delete of the item would break. Each link has the `system` and the `entity` it belongs to, a `name`, its `external_id` and the `reason` it blocks the delete. `links` is empty when nothing outside the store depends on the item. Call it before [Delete an item permanently](/api-reference/trash/delete-an-item-permanently). It works only for an item in the trash: an item that is not in the trash, a live one included, returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication (New)](/authentication#set-up-a-client). To try the call here, click **Try it**, set `store` to your store's host name and paste an access token. Get the token as shown in [Authentication (New)](/authentication#calling-the-api-directly), or in [Authentication (Legacy)](/authentication-legacy#calling-the-api-directly) if your store signs in with a redirect URI and an auth string.</Note>
