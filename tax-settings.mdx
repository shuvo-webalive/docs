The Tax settings API has three endpoints, and you can call every one from all seven SDKs. All three use the path `/api/v4/admin/settings/tax`.

<Warning>
  **Wrap a write in `tax_settings`.** The store also accepts `tax` as the wrapper. A body wrapped in
  `settings` and a body with no wrapper are each rejected with `400`.
</Warning>

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [Get tax settings](/api-reference/tax-settings/get-tax-settings) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `…/tax` | Returns the nine tax settings in one `tax_settings` object, and `group_meta`. |
| [Update tax settings](/api-reference/tax-settings/update-tax-settings) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#b45309"}}>PUT</span> | `…/tax` | Changes the tax settings you send inside `tax_settings` and returns all nine. |
| [Patch tax settings](/api-reference/tax-settings/patch-tax-settings) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#7a5af8"}}>PATCH</span> | `…/tax` | Changes the tax settings you send inside `tax_settings` and returns all nine. |

## Before you call

Register your credentials once when your app starts, as shown in
[Authentication (New)](/authentication), or in [Authentication (Legacy)](/authentication-legacy) if your store
signs in with a redirect URI and an auth string. Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **A write changes only the fields you send.** `PUT` and `PATCH` both merge: every field you leave
  out keeps its stored value.
- **Write the custom tax profile as `custom_tax_profile_id`.** The read returns the profile as
  `custom_tax_profile`, but a write that contains `custom_tax_profile` or `calculated_by` is rejected
  with `400 unknown_field`.
- **Write `tax_region` as an object.** `{"country_code": "AU"}` sets the region. `{"country_tax_id": 1}`
  is accepted but leaves `tax_region` as `null`. A bare id is rejected with `400`.
- **The `group_meta` links for tax profiles and tax rules return `404`.** `group_meta` names
  `/api/v4/admin/tax/profiles` and `/api/v4/admin/tax/rules`. Read the tax profiles at
  `/admin/tax_profiles` and the tax rules at `/admin/tax_rules` instead.
- **The old path `/admin/tax/settings` returns `404` with the message `Unknown tax path`.** Add
  `field_metadata=true` to a read to also get `field_metadata`, a description of each field.
