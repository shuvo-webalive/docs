## Get up and running in three steps

<Steps>
  <Step title="Install the SDK">
    Add the SDK Knowledge Base package to your project using your preferred package manager.

    ```bash
    npm install sdk-knowledge-base
    ```
  </Step>
  <Step title="Authenticate your client">
    Initialize the SDK client with your API key. Store your key in an environment variable so it never touches source control.

    ```bash
    export SDK_KB_API_KEY="your-api-key-here"
    ```
  </Step>
  <Step title="Make your first call">
    Create a client instance and call any endpoint. The SDK handles token passing, retries, and response parsing automatically.

    ```typescript
    import { SdkKnowledgeBase } from "sdk-knowledge-base";

    const client = new SdkKnowledgeBase({
      apiKey: process.env.SDK_KB_API_KEY,
    });

    const result = await client.resources.list();
    console.log(result.data);
    ```
  </Step>
</Steps>

## SDK initialization at a glance

The snippet below shows a fully configured client with the most commonly used options. You only need the `apiKey` to get started — everything else is optional.

```typescript
import { SdkKnowledgeBase } from "sdk-knowledge-base";

const client = new SdkKnowledgeBase({
  apiKey: process.env.SDK_KB_API_KEY, // required
  baseUrl: "https://api.sdkkb.io/v1", // default, override for proxies
  timeout: 10_000,                    // ms, default 30 000
  maxRetries: 3,                      // automatic exponential back-off
  logLevel: "info",                   // "debug" | "info" | "warn" | "error"
});
```
