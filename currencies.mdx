The Currencies API has eleven endpoints, and you can call every one from all seven SDKs. Every path starts with `/api/v4/admin/currencies`.

<Warning>
  **Setting the base currency changes the `conversion_rate` of every currency in the store.**
  [Set the base currency](/api-reference/currencies/set-the-base-currency) divides every currency's rate, inactive ones included,
  by the new base's old rate, and sets a new `updated_at` on every currency. Rates are kept to 6
  decimal places, so switching back does not always restore a rate exactly. Product `base_price` values do not change.
</Warning>

## Before you call

Register your store's credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **Send the fields at the top level of the body, not inside `currency`.** Create, replace and
  update all take the bare record. A body wrapped in `currency` is rejected with `400`: `currency`
  is reported as `unknown_field`, and `name`, `code` and `symbol` as `required`. Responses return the
  currency inside `currency`.
- **`PUT` replaces a currency, and `PATCH` changes only the fields you send.**
  [Replace a currency](/api-reference/currencies/replace-a-currency) resets every field you leave out: `conversion_rate` to `1`,
  `rounding` to `nearest`, `precision` to `2`, `active` to `true` and `country` to the store's default
  country. To change one field, use [Update a currency](/api-reference/currencies/update-a-currency).
- **Exactly one currency is the base, and you cannot replace, update or delete it.** `PUT` and `PATCH` on
  the base currency are rejected with `400`, and `DELETE` with `409`. Make another currency the base
  first with [Set the base currency](/api-reference/currencies/set-the-base-currency). That call is the only way to move the flag,
  and it rejects an inactive currency.
- **A listing returns 20 currencies per call unless you send `limit`.** `limit` takes `1` to `100`,
  and `pagination.limit` shows the page size applied. To get more, send a higher `offset` while
  `pagination.has_next` is `true`. `page` is rejected with `400`. `q` does not filter the listing:
  the store ignores it and returns every currency, so send `search` instead.
- **`code` is any three letters, stored in upper case.** The store does not check it against
  ISO 4217, even though `field_metadata` describes it as an ISO 4217 code. `code` and `name` must
  each be unique: a taken one is rejected with `409`. `name` is compared without regard to letter case.
