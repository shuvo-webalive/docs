WebCommander exposes a store's admin data through the **v4 REST API**. Seven SDKs wrap it with the
same calls in every language, so a call you learn in one reads the same in the others. These docs
cover only the endpoints that **all seven SDKs implement**: if a call is documented here, you can
make it from any of them.

## What every SDK does for you

<CardGroup cols={2}>
  <Card title="Signs in for you" icon="key">
    Exchanges your credentials for an access token, caches it and renews it before it expires.
  </Card>
  <Card title="One client for everything" icon="cubes">
    Each area is a property on the client, and each endpoint is a method on it.
  </Card>
  <Card title="Responses as sent" icon="brackets-curly">
    The body exactly as the API returned it, with an optional typed view over the top.
  </Card>
  <Card title="Failures you cannot miss" icon="triangle-exclamation">
    A non-2xx status is a failure, and so is a `200` whose body says `"isSuccess": false`.
  </Card>
</CardGroup>
