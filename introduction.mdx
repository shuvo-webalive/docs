The WebCommander **v4 REST API** lets you read and change a store's admin data from your own code.
Seven SDKs, one per language, call it for you with the same set of methods, so what you learn in
one SDK applies to the others. These docs
cover only the endpoints that **all seven SDKs implement**: if a call is documented here, you can
make it from any of them.

## What every SDK does for you

<CardGroup cols={2}>
  <Card title="Signs in for you" icon="key">
    Exchanges your credentials for an access token, caches it and renews it before it expires.
  </Card>
  <Card title="One client for everything" icon="cubes">
    Each area, such as customers, has one method per endpoint, for example
    `client.admin_customers.get_customers()` in Python.
  </Card>
  <Card title="Responses as sent" icon="brackets-curly">
    Each method gives you the response body exactly as the API sent it. When the response holds
    customers or other records, you can also read it as a typed object.
  </Card>
  <Card title="Failures you cannot miss" icon="triangle-exclamation">
    The SDK reports any non-2xx status as a failure. It also reports a `200` whose body contains
    `"isSuccess": false`, which the API returns for a URL it cannot route.
  </Card>
</CardGroup>
